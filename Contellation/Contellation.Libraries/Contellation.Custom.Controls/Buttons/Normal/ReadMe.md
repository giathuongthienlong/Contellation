# Button - Contellation Custom Controls

**Contellation Button** là control Button được tùy chỉnh mạnh mẽ, hỗ trợ nhiều kiểu Appearance, TitleBar buttons và Icon.

---

## Tính năng nổi bật

- Hỗ trợ nhiều **Appearance** (Primary, Secondary, Danger, Success, Info, Caution, Dark, Light, Transparent)
- Hỗ trợ **TitleBar Button** (Close, Minimize, Maximize, Restore)
- CornerRadius linh hoạt
- Hỗ trợ Icon (FontFamilyIcon hoặc ContentPresenter)
- Trạng thái hover & pressed mượt mà
- Dễ sử dụng với MVVM

---
